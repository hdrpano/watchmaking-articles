Example Measurement Files

This directory contains example timing measurements recorded from mechanical watch movements using Witschi timing equipment and ONEOF Accuracy².

The files are provided as reference datasets for the Mechanical Watch Performance Analysis application and the accompanying technical article.

They can be used to reproduce and explore analyses including:

rate and amplitude evaluation,
statistical measurement analysis,
Fast Fourier Transform (FFT),
dominant frequency detection,
rate stability,
amplitude stability,
isochronism,
realised isochronism (ICI),
and the Dynamic Performance Index (DPI).
File Formats

The directory may contain measurement data exported from:

Witschi timing instruments
ONEOF Accuracy²

These example files can be loaded directly into the Performance Analysis application where supported.

Important Note

The calibres represented by these measurement files are not COSC-certified movements.

The data therefore do not represent official COSC measurements or certification results. They are provided exclusively as engineering examples for demonstrating and reproducing the analysis methods described in the accompanying article.

Measurement results depend on the instrument, measurement configuration, movement condition, winding state, position, measurement duration and environmental conditions.

The datasets should therefore be interpreted as experimental measurement examples rather than as definitive assessments of a particular calibre or manufacturer.

Purpose

Providing the original measurement data makes the proposed analysis methodology independently reproducible.

Users can apply the same FFT, statistical and dynamic analysis methods to these files and compare the results with measurements from their own mechanical watches.

# Watchmaking Technical Articles

This repository contains technical articles, measurement data, software and supplementary material related to mechanical watch engineering and performance analysis.

The objective is to provide transparent and reproducible engineering methods that can be used by watchmakers, manufacturers, researchers and technically interested collectors.

## Mechanical Watch Performance Analysis

One of the projects presented in this repository introduces a complementary approach to evaluating mechanical watch performance based on three different engineering domains:

* **Construction Efficiency** — Horological Density Factor (HDF)
* **Regulation Quality** — COSC Concours Formula
* **Dynamic Oscillator Quality** — Dynamic Performance Index (DPI)

These methods are not intended to replace one another. Each evaluates a different aspect of mechanical watch performance and together they provide a broader engineering perspective on the behaviour of a movement.

## Performance Analysis Application

To ensure that the proposed methodology is fully reproducible, the calculations described in the article have been implemented in the **Mechanical Watch Performance Analysis** application.

Rather than requiring manual calculations, the software automatically evaluates the three engineering domains introduced above.

The application imports timing data recorded by modern timing instruments, including:

* Witschi TXT measurement files
* CSV data generated by ONEOF Accuracy²
* Generic compatible CSV measurement data

After importing a measurement, the user enters the basic movement parameters required for the HDF calculation, including balance inertia, frequency, power reserve and movement dimensions.

The software then performs the dynamic analysis automatically.

## Engineering Analysis

Depending on the available measurement data and movement parameters, the analysis includes:

* Horological Density Factor (HDF)
* COSC Concours performance evaluation
* Dynamic Performance Index (DPI)
* FFT spectrum and dominant frequencies
* Rate stability analysis
* Amplitude stability analysis
* Isochronism analysis
* Realised isochronism (ICI)
* Statistical evaluation of the measurement
* Measurement outlier detection
* Complete engineering PDF report with calculated parameters and diagrams

## Dynamic Performance Index

The **Dynamic Performance Index (DPI)** extends conventional static timing evaluation by analysing the dynamic behaviour of the oscillator over time.

The method uses time-series measurements of rate and amplitude and combines statistical analysis with frequency-domain analysis using the Fast Fourier Transform (FFT).

This makes it possible to identify dynamic variations and periodic behaviour that may not be visible from conventional positional rate measurements alone.

## Example Measurement Data

The [`mesure`](./mesure) directory contains example measurement files recorded with Witschi and ONEOF Accuracy instruments.

These files can be used to reproduce the analyses described in the article and to experiment with the FFT and DPI evaluation methods.

The measured calibres included in this directory are **not COSC-certified movements** and the measurement files should not be interpreted as official COSC test results.

## Availability

The **Mechanical Watch Performance Analysis** application has been developed in Python and is available free of charge for:

* Windows
* macOS

Its primary objective is to make the methodology presented in the accompanying article transparent, reproducible and easily accessible.

By providing the mathematical framework, example measurement data and a software implementation, the proposed methods can be independently examined and applied to virtually any mechanical watch for which suitable timing data are available.
